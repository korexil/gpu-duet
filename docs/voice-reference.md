# 准备参考音：想要什么效果，用什么办法

零样本克隆会照搬参考音的音色、语速、节奏和语调习惯：参考音快，合成就快（实测参考 8.5 字/秒，克隆出来 7.9～8.3 字/秒）。所以先把参考音调成想要的样子，比事后改合成结果省事。下面是一次为演示视频选声音的过程里验证过的办法，按「想要的效果」分；哪种声音好听没有标准答案，听的人说了算。

## 想要一个不是任何真人的声音

- **Qwen3-TTS CustomVoice 的预设说话人**（`generate_custom_voice`，speaker 如 `vivian`、`ryan`、`aiden` 等，Apache-2.0）：阿里调过的声音，起伏和气息都比较稳，配一句 `instruct` 就能改口吻，比如「说话轻快、有精神，节奏快慢有变化，不要匀速，语气自然」。
- **Qwen3-TTS VoiceDesign**（凭文字描述造声）：自由度高，但容易开头发音怪、语调平、气音多；描述里明确写「语调有起伏」「开头清楚」「气息干净」能改善，不能根治。

## 想要同样的语调，只是慢一点

指令里加「放慢」会连语调一起变。更可靠的是：指令一字不改，**多生成十来条**。同一条指令的语速会在 5.8～8.5 字/秒之间浮动，用脚本量语速（汉字数 ÷ 有声时长）和音高起伏（`librosa.pyin` 的 F0 半音标准差）先筛，再交给人听。

## 只想让句子之间喘口气

在参考音**已有的停顿正中间**加长，不要在停顿末尾硬接：

1. 用 5 ms 帧的 RMS 找出 ≥ 80 ms 的安静段（-40 dB 以下），再向两侧扩到 -28 dB，把轻的换气声包进来。
2. 停顿内部整段换成该处最安静的 60 ms 底噪做成的循环（正放接倒放，接头连续），只保留与前后字相接的 25 ms 衰减和起音。
3. 两端各 15 ms 交叉淡化，每处 +100～150 ms。

字的部分一个采样不碰。

## 不要碰的

改到有声部分波形的变速都会被听出来：相位声码器变速有金属味，WSOLA 变速像掉帧的语音通话。要慢，就回到上一节多生成几条去筛。

## 收尾

模型在结束符处停下时最后一个字还在发声，没有收音，听起来像被掐断。引擎在结束符后再把最后一帧的 code 多喂 3 帧（`QWEN3_TTS_TAIL_PAD_FRAMES`，默认 3）让声码器把尾音渲染出来；用 Python 推理做参考音时是另一种做法：在解码前把最后一帧重复 4 次，效果相同。

## 最后一步

选定的 wav 和逐字文本交给 `tts-service/extract_voice.py`（或 `qwen3-tts-cli --extract-icl-prompt`）生成声音提示，再用引擎合成几句不同内容、不同种子的话听一遍，参考音里没暴露的问题（比如某些字的发音）会在这一步出现。
